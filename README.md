## 🧑‍💻 关于我 / About Me


我是华南师范大学（SCNU）RoboMaster VANGUARD 战队算法组工程师，主要负责机器人的视觉感知与运动控制相关算法开发。日常在 **算法 ↔ 嵌入式 ↔ 仿真** 三者之间来回穿梭：从模型训练、部署到 Jetson 等边缘平台，到底层 STM32 / FPGA 的控制实现，再到 Isaac Sim / Gazebo / MuJoCo 中的仿真验证。

目前重点关注 **具身智能（Embodied AI）**、**BEV 感知** 与 **SLAM**，并探索将这些技术应用于 RoboMaster 机器人平台，让机器人具备更强的自主感知、定位、决策与控制能力。

除了代码，我也喜欢动手做东西——3D 打印、激光切割、CNC、航拍与摄影都是我的爱好。我习惯把工程与视觉设计结合起来，让做出来的东西不仅"能用"，而且"好看"。


I'm an algorithm engineer in the SCNU RoboMaster VANGUARD team, focusing on vision perception and motion control for robotics. My daily work shuttles between **algorithms, embedded systems, and simulation** — from model training and deployment on edge devices like Jetson, to low-level control implementation on STM32 / FPGA, and validation in Isaac Sim / Gazebo / MuJoCo.

I am currently focusing on **Embodied AI**, **BEV Perception**, and **SLAM**, exploring how to integrate them into the RoboMaster platform so that robots can achieve stronger autonomous perception, localization, decision-making, and control.

Beyond code, I love making physical things — 3D printing, laser cutting, CNC, aerial photography, and photography are all part of my toolkit. I enjoy bridging engineering and visual design so that what I build is not only functional but also beautiful.

## 🔬 研究方向 / Research Interests

- 🧠 **具身智能 / Embodied AI** — 感知-决策-控制闭环、VLA、机器人学习
- 🛰️ **BEV 感知 / BEV Perception** — 多相机 BEV 特征融合、BEV 检测、Occupancy
- 🗺️ **SLAM** — 视觉 / 激光 SLAM、建图、定位、多传感器融合
- 👁️ **机器视觉** — 目标检测与跟踪、相机标定、视觉定位
- 🦾 **机器人运动学** — 正逆解、轨迹规划、动力学建模
- 📡 **传感器融合** — IMU / 视觉 / 里程计多源融合与状态估计
- 🎛️ **机器人控制** — 云台与底盘控制、PID、LQR、RL
- 🖥️ **机器人仿真** — Isaac Sim / Gazebo / MuJoCo 仿真环境搭建与验证
- ⚡ **嵌入式控制算法** — STM32 / FPGA / Jetson 平台上的实时控制实现

---

- 🧠 **Embodied AI** — Perception-decision-control loop, VLA, robot learning
- 🛰️ **BEV Perception** — Multi-camera BEV feature fusion, BEV detection, Occupancy
- 🗺️ **SLAM** — Visual / LiDAR SLAM, mapping, localization, multi-sensor fusion
- 👁️ **Computer Vision** — Object detection & tracking, camera calibration, visual localization
- 🦾 **Robot Kinematics** — Forward/inverse kinematics, trajectory planning, dynamics modeling
- 📡 **Sensor Fusion** — Multi-source fusion and state estimation (IMU / Vision / Odometry)
- 🎛️ **Robot Control** — Gimbal & chassis control, MPC, adaptive control
- 🖥️ **Robot Simulation** — Building and validating in Isaac Sim / Gazebo / MuJoCo
- ⚡ **Embedded Control Algorithms** — Real-time control on STM32 / FPGA / Jetson
